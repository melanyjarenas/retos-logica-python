#**📌 Contexto y Origen de este Repositorio**

Todo comenzó en un punto de quiebre donde la frustración y las dudas técnicas amenazaban con frenar el proceso. En lugar de abandonar, transformamos esa incertidumbre en un método de aprendizaje paso a paso, enfocado en:

Resolver retos estilo entrevista técnica de forma independiente.

Comprender a fondo el "porqué" detrás de cada concepto (alcance de variables, estructuras de control, sintaxis avanzada).

Pasar de pensar solo en el código individual a diseñar reportes globales y estructurados.

#**📂 Estructura de Retos y Proyectos**
Cada carpeta contiene el código fuente comentado y la explicación detallada de los conceptos aplicados:


1️⃣ Reto 1: Clasificación de Tiempos Logísticos
Descripción: Automatización para clasificar tiempos de procesos utilizando listas paralelas y la función zip().

Conceptos clave: Sincronización de listas, iteración limpia y presentación estructurada en consola.

---

2️⃣ Reto 2: Auditoría Nocturna de Lotes
Descripción: Sistema de validación de códigos de lotes para determinar categorías especiales y de revisión técnica.

Conceptos clave:

Ámbito y alcance de variables locales (scope).

Inicialización correcta de contadores independientes para evitar errores de tipo UnboundLocalError.

Uso riguroso del operador módulo (% 3 == 0 y % 3 != 0) y la indentación.

---

3️⃣ Reto 3: Control de Calidad de Insumos (Cera de Soya)
Descripción: Módulo de auditoría para un inventario de cajas de cera, clasificándolas por rangos de peso.

Conceptos clave:

Encadenamiento elegante de fronteras numéricas dobles en Python (ej. 50 <= peso_caja <= 150), eliminando condiciones anidadas redundantes.

Generación de reportes globales al finalizar el bucle for mediante acumuladores y operaciones matemáticas integradas en cadenas de texto formateadas (f-strings).
